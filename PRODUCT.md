# slopp

Open-source playground.
Paint, breathe, draw, listen, transcend.
Release your inner child

Tagline approved on 18 October 2026. Previously called Untranslatable; existing source
URLs and stored drawing identifiers remain compatible.

A shared abstract artwork to explore and build together. Draw into the air,
release the gesture into depth, and leave it for someone else to find.

The approved 13 October direction is six distinct, connected environments:
fine filaments, pleated colour, asymmetric cut-outs, dry overprinting, nested
contours and spare oversized gestures. Cream ground and shared motifs keep
the work related. There is no representational imagery.

Each place has a small local palette and three simple drawing tools. The
round surprise button chooses among ten gesture families and animates the
result into existence. Drawings keep their position, orientation, colour and
environment. Visitors can turn, move freely, return, control drift speed and
pinch to travel. Making and sharing a drawing remains the central interaction.

Shared contributions live in server storage. Drafts stay in the visitor's
browser. No account or profile system is requested. The code is open source;
the world and source can be downloaded. The first artworks remain in an archive.

Stack: Three.js with unlit WebGL geometry, browser JavaScript and native
controls; Web Request API on Bun/SQLite locally or Worker/D1 when deployed.
Alex approved the six-environment build for public release on 13 October.
Keep release checks focused on drawing, shared persistence and exploration.

The optional soundtrack uses Alex's stem recordings across six related musical
palettes. Movement, drawing, proximity and surprise shapes influence the music,
with space for quiet. Sound starts only by choice, with mute and independent
volume. The music remains all rights reserved; code and drawing licences are
unchanged.

16 October: the opening presents the original environment artworks at full
scale. Community drawings begin arriving after thirty seconds of visible use,
one weighted random selection every eight seconds, with an eight-second fade
(immediate with reduced motion). Once introduced, a drawing stays in its place;
turning never swaps it out. Supporting environment pieces occupy 7.5% of the
spatial cells outside the opening, keeping occasional quiet stretches between
the full-size artworks. Shared traces have generous, stable display spacing
and leave room around the core artworks. Find a trace immediately visits a saved
drawing, with no immediate repeat and screen-aware framing. Higher automatic
composition ranks increase selection chances; every drawing remains eligible.
Owner corrections can feature a piece, restore automatic choice, or show it
less often through the local curation page (`bun run curate`). This geometric
heuristic is a starting preference, not an objective assessment of beauty.
A short guide can be closed and reopened from Help.
Drawing can continue while travelling. Hold or drag the pen to leave a trail;
W/A/S/D still moves the viewer. Pause drift / Start drifting remains visible
with the drawing tools. The saved line keeps its depth when released or
revisited. Reduced motion starts still until movement is explicitly chosen.
Entering drawing mode slows drift to a gentle pace, preserving slower speeds
and Pause. A drawing pace slider lets the visitor speed up again. Close keeps
unfinished work as a private local draft; only Let it go shares it. A successful
release restores the speed and pause setting from before drawing began.
The labelled Turn sound on / Turn sound off control remains visible while idle
or drawing. Its label describes the action. The guide explains that the
immersive soundscape responds to drawing, movement and discovering traces.

An empty central view gets a distant artwork after five visible seconds,
fading into place over four seconds. It stays anchored as the visitor moves.
The opening uses core art; after thirty seconds these appearances alternate
with quality-weighted community drawings when available. They are local
copies, never new shared records. Drawing and manual navigation interrupt
the wait; automatic drift continues it. This keeps unattended exploration
populated without filling an already occupied view. Sparse views soften the
continuous musical layer; emptiness never switches enabled sound off.

The chimes have a separate six-decibel reduction; pads and the ambient layer
retain their levels. Turn around reverses both horizontal direction and vertical
tilt, keeping the visitor in place and bringing the route behind into view.

Downloaded images and animations use a simple black sloppworld.com signature
at the bottom right. It stays visible and stationary throughout each animation.
